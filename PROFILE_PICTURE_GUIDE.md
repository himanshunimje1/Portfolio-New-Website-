# Professional Profile Picture Guide

## ✅ What I've Added

I've updated your portfolio to include a professional profile picture section in the About page. The image will display beautifully with:
- Rounded corners with elegant shadow
- Hover effects
- Responsive design (works on all devices)
- Automatic fallback to icon if image not found

## 📸 How to Add Your Profile Picture

### Step 1: Prepare Your Image

1. **Get a professional photo** with:
   - Business attire (suit recommended)
   - Good lighting
   - Clean background
   - Professional pose
   - High resolution

2. **Edit/Resize if needed:**
   - Recommended size: **600x600px to 800x800px** (square)
   - Format: JPG, PNG, or WebP
   - File size: Keep under 500KB for fast loading
   - Use tools like:
     - [TinyPNG](https://tinypng.com/) - Compress images
     - [Canva](https://www.canva.com/) - Edit/resize
     - [Remove.bg](https://www.remove.bg/) - Remove background

### Step 2: Add to Portfolio

1. **Save your image as:** `profile.jpg` (or `profile.png`)
2. **Place it in:** `/Users/himanshunimje/New Portfolio 2026/images/`
3. **The file path should be:** `images/profile.jpg`

### Step 3: Verify

1. Open `index.html` in your browser
2. Scroll to the "About Me" section
3. Your profile picture should appear on the left side

## 🎨 Image Requirements

- **Name:** `profile.jpg` or `profile.png`
- **Size:** 600x600px to 800x800px (square recommended)
- **Format:** JPG, PNG, or WebP
- **File size:** Under 500KB (optimized)
- **Aspect ratio:** Square (1:1) works best

## 💡 Tips for Professional Photo

1. **Dress professionally** - Business suit or formal attire
2. **Good lighting** - Natural light or professional studio lighting
3. **Clean background** - Solid color or blurred professional background
4. **Professional pose** - Smile, confident posture, look at camera
5. **High quality** - Use a good camera or smartphone with good camera

## 🔄 If Image Doesn't Show

If the image doesn't appear:
1. Check file name is exactly `profile.jpg` (case-sensitive)
2. Verify file is in the `images/` folder
3. Clear browser cache and refresh
4. Check browser console for errors (F12)
