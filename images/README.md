# Images Folder

Add your images to this folder:

## Required Images

1. **profile.jpg** (or .png)
   - Your profile/headshot photo
   - Recommended size: 600x600px or larger (square aspect ratio)
   - Will be displayed in the About section

2. **project-1.jpg** (or .png)
   - Screenshot/image for "E-Commerce Platform" project
   - Recommended size: 1200x675px (16:9 aspect ratio)

3. **project-2.jpg** (or .png)
   - Screenshot/image for "Task Management App" project
   - Recommended size: 1200x675px (16:9 aspect ratio)

4. **project-3.jpg** (or .png)
   - Screenshot/image for "Analytics Dashboard" project
   - Recommended size: 1200x675px (16:9 aspect ratio)

## Image Formats Supported

- JPG/JPEG
- PNG
- WebP (recommended for better performance)

## Notes

- If images are not found, the portfolio will automatically show placeholder icons
- Images should be optimized for web (compressed) to ensure fast loading
- Use tools like [TinyPNG](https://tinypng.com/) or [Squoosh](https://squoosh.app/) to compress images

## Adding Images

Simply place your image files in this folder with the exact names listed above, and they will automatically appear on your portfolio website.
